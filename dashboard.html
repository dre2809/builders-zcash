Zcash Address Types
Unified Addresses (u1…) bundle transparent, Sapling, and Orchard receivers into one address. Wallets automatically use the most private available pool when sending to a UA.
Z3 Node Stack
Zebra syncs the chain from peers. Zaino indexes and serves compact blocks via gRPC. Wallets and apps connect to Zaino — no full node required on-device.
Zcash Shielded Pools
Orchard (2022) is the current recommended pool. It uses Halo2 — no trusted setup, stronger security, recursive composability. All new development should target Orchard via Unified Addresses.
